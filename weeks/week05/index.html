WEEK 05

模型與 context window

Codex 可以在對話中途換模型，但每個模型都有自己的 context window。這週看換模型時發生什麼事、用量為什麼會一次跳高，以及開工前怎麼選、真的要換時怎麼換。

影片 01不要一直換模型

  1. 每個模型都有自己的 context window。用 GPT-6 Luna 做了一陣子，讀過的對話都裝在 Luna 自己的 context window 裡，對話越長，裝得越滿。

  2. 中途換模型，新模型要從頭讀一遍。換成 GPT-6.1 Sol 之後，Sol 要把整段對話放進它自己的 context window，所以換過去的那一輪，用量一次跳很高。

  3. 換模型會讓快取失效。Codex 平常用快取（prompt caching）便宜地重用前面讀過的內容；OpenAI 官方文章〈Unrolling the Codex agent loop〉說明，中途換模型，快取會失效，整段要重新讀。

  4. 開工前就選好模型。選好之後，這段對話就一路用它。真的要換，先在原本的對話裡請目前的模型寫一段交接摘要，再開新對話、換模型、貼上摘要；也可以寫進 Week 3 學過的 AGENTS.md、progress.md。

  5. 影片裡的面板和數字都是示意。context window 面板借用 Claude Code 的 /context 畫面，Codex 看不到這張表；長條和用量也不是實測數字。
