WEEK 04

AI Agent 內建瀏覽器

AI Agent 控制瀏覽器的方法有很多種，Codex 自己就帶了一個瀏覽器。這週看它怎麼打開網頁、卡住時發生什麼事，以及它實際用 Blockbench 做出一組方塊桌椅。

影片 01AI Agent 內建瀏覽器

  1. AI Agent 控制瀏覽器的方法有很多種。Playwright 適合大規模背景自動化（含測試），Chrome DevTools MCP 適合特定場景，Chrome Plugin & Extension 綜合能力高，內建瀏覽器支援多、好上手，Computer Use 效率低、是下下之選。

  2. Codex 自己帶了一個瀏覽器。輸入「打開內建瀏覽器，並隨意搜尋做測試」，右邊就會打開瀏覽器面板，由 Codex 幫你操作網頁。

  3. 卡住時，它會告訴你卡在哪裡。叫它用 Blockbench 做方塊桌椅時，它回報瀏覽器控制工具缺少 26.928.20755/browser-service.mjs，所以無法操作頁面。

  4. 它能自己找到原因、修好。工具指向一個不存在的版本目錄；它用本機完整的瀏覽器元件建立相容副本、保留原件，再實際測試連線，控制連線就恢復了。

  5. 實際操作要花時間。從修復到做出方塊桌椅並存檔，整段工作花了 22 分 34 秒；影片裡的錄影有快轉，畫面上標出倍數。
