資料使用課程來源清冊 41 列、18 欄及 2026-10-02 已核實快照，只收錄 26 處可證實銀杏地點；座標為近似代表點，不是銀杏樹精確位置。官方當季葉況未確認，過去紀錄一律保留日期。

路線為自選停靠順序及直線示意；未使用步行路網，不是即時導航。每分鐘80公尺估算時間，不含繞路與停留。
