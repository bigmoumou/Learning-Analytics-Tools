# 東京銀杏地圖

直接開啟 index.html；不需安裝套件、登入或後端。地圖底圖及公開步行道路服務需要連線。建議以瀏覽器開啟；若瀏覽器限制檔案頁的道路請求，改用外部導航。

## 更新來源

data.js 包含景點、課程來源清冊、近似座標與歷史紀錄。新增葉況前確認原文的觀測日、對象及來源網址；不可把公告發布日或地面落葉當成樹冠實測。沒有證據時保留待確認。來源查核日與整理日分開。

歷史紀錄保留原日期。氣象廳東京1991–2020平年值黃葉11/23、落葉12/3，不能覆寫園區狀態。圖例是概念插畫，不代表單株葉片特徵。

## 地圖與散步

地圖為 Leaflet / OpenStreetMap，座標是課程資料中的園區代表點，不保證入口位置。公開 FOSSGIS OSRM 步行服務回傳道路幾何與道路距離，再依每分鐘80公尺估算步行時間；每站15分鐘只是規劃建議。服務不可用時保留清單與外部導航，不用直線替代道路距離。車站欠缺已核對入口座標時交由外部地圖查詢。

收藏與清單保留於本機瀏覽器；儲存被封鎖时仍可操作。定位只在使用者按鈕同意後請求。動畫可關閉，並尊重系統減少動態效果設定。
