# 銀杏觀測誌

整理東京銀杏觀賞資訊的靜態網站：地圖與觀賞階段、散步路線規劃、可搜尋的來源清單。
當季狀態與觀測只採官方來源；查不到、不能核實的一律標「待確認」。地圖上的園區代表點座標來自共用快照的公開圖資（非官方座標），在網站上都有標明。

教學使用・非營利。實際開放與景況以管理單位公告為準。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 網頁入口，三個區域：「地圖與狀態」「散步路線」「來源」 |
| `style.css` | 版面與視覺（米色方格紙、琥珀／鏽紅／橄欖色、等寬字資料標籤） |
| `script.js` | 互動程式：分頁、搜尋篩選、階段、自寫的 OpenStreetMap 地圖、觀測卡、散步規劃、來源清單 |
| `data.js` | 資料檔：26 個地點、過去季紀錄、2026 官方動態、79 筆來源（重複網址已合併，含 1 筆代表點座標的快照說明） |
| `README.md` | 本說明 |

只用原生 HTML、CSS、JavaScript。沒有框架、套件、建置工具、伺服器或資料庫。
地圖沒有使用 Leaflet 等地圖套件，而是自寫的圖磚瀏覽器（Web Mercator 座標換算、拖曳、滾輪／雙指／按鈕縮放、鍵盤操作）。

## 開啟方式

- 直接雙擊 `index.html`，用瀏覽器開啟即可。
- 需要網路連線才會載入地圖圖磚（OpenStreetMap）與字型（Google Fonts）。離線或圖磚被封鎖時，地圖區會顯示說明，標記仍畫在方格底上，清單、篩選、散步規劃與來源都照常可用。
- 散步清單存在瀏覽器的 localStorage，只留在這台電腦的這個瀏覽器，不會上傳；瀏覽器禁止儲存時，清單仍可在本次瀏覽中使用。

## 部署方式

- 把整個資料夾（五個檔案）上傳到任何靜態網站主機，例如 GitHub Pages、Cloudflare Pages 或 Netlify，入口是 `index.html`。
- 不需要建置步驟或後端。所有路徑都是相對路徑；檔名大小寫要保持一致。
- 部署到正式網址後，瀏覽器會附上來源網址（Referer）向 OpenStreetMap 要圖磚，比從本機檔案開啟更符合 OpenStreetMap 的圖磚使用政策。

## 功能

**地圖與狀態**
- 六個觀賞階段：青葉 → 色づき始め → 黄葉進行 → 見頃 → 落葉始め → 落葉，另有「待確認」。
- 點選階段會篩選地圖與清單，並列出該階段的當季已核實地點。目前每個階段都是 0 處，並顯示原因。過去季的官方紀錄另外列在下方，標明日期，不當作現況。
- 搜尋（中文、日文、假名、編號都可，日文新字體與繁體字互通，例如「大田黒」可找到「大田黑公園」）、行政區篩選、地圖／清單切換。
- 地點觀測卡：當季狀態與觀測日期、2026 官方動態、過去季紀錄、官方說明的銀杏位置、園區代表點、官方資訊摘錄（依官方頁面整理，多為日文；附日期的活動與公告分成「官方活動」「官方公告」兩欄）、官方來源連結（資料表另附的第三方網址不列入官方來源，另外標為「第三方參考」）、加入散步清單、Google 地圖步行導航（點選後才開啟）。

**散步路線**
- 手動加入、移除、上移／下移排序。
- 自動產生「約 30 分鐘」「約 1 小時」路線，可存成散步清單。
- 結果列出順序、每段直線距離與估時、總時長，以及全程與各段的 Google 地圖步行導航。

**來源**
- 可搜尋，分為「官方」「氣象廳」「第三方整合」「排除・失效」。
- 每筆列出來源名稱、網址、查核日期、它支持的資料、注意事項，以及沒有放上地圖的原因。
- 揭露重複合併原則、資料限制與最近查核日期。

## 重複合併原則

1. 同一個網址只列一次，並寫出所有引用它的資料列。例如東京都公園協會「2025 年度紅葉情報新聞稿」PDF 被 15 列引用，合併成一筆共用來源；氣象廳生物季節資料首頁（3 列）與 Jorudan 國立大學通頁（2 列）也各合併成一筆。
2. 同一列的主要網址與證據頁相同時只顯示一次，並同時標出兩種用途。
3. 多列完全相同的說明合併成一則：TKG-002～013 的角色、發現、更新頻率與建議檢查頻率文字相同，合併為「共用說明」，各列只保留自己的注意事項。
4. 東京大學（TKG-040）拆成本鄉、駒場兩個地點；「皇居外苑・北之丸公園」（TKG-030）只採用已證實有銀杏的北之丸公園。
5. 善福寺川綠地與和田堀公園在 2025 年名單中是同一列，本站依資料表分成兩個地點，但不假設兩處各有獨立觀測。
6. 不是單一銀杏觀賞地點的列（入口、氣象廳、觀光入口、第三方平台、楓樹或物種未證實、失效來源）只列在「來源」，不放上地圖。
7. 顯示時把資料表中零星的簡體字改成繁體字，內容不變。

## 假設（遇到歧義時採用的保守預設）

- **地點範圍**：只放資料表能證實有銀杏的單一地點，加上同一官方網域證實有銀杏的靖國神社、北之丸公園、東京大學本鄉與駒場、國立大學通，共 26 處。沒有為了湊數加入無來源的地點。
- **當季**：指 2026 年秋季。只有官方來源同時明確寫出銀杏、地點、日期時，才標示當季狀態。截至 2026-10-02 沒有這樣的來源，所以全部是「待確認」。
- **階段對應**：過去季紀錄只有在原文明確使用階段用語（「見頃／みごろ」「色づき始め」）時才對應到階段；其他寫成「未標明階段」。不從平年值、照片或往年經驗推測。
- **行政區**：依資料表的地區欄；跨區的園區同時列在各區；資料表寫「等」時只取第一個區，完整範圍寫在觀測卡。明治神宮外苑在資料表中沒有寫行政區：外苑官方所在地是新宿區霞ヶ丘町，銀杏並木的代表點位於港區北青山一帶（共用快照的座標註記），所以新宿區與港區都列。
- **座標**：使用共用快照的代表點（OpenStreetMap／Nominatim、Wikipedia 等公開圖資平均或推定，非官方座標），一律標示為「園區代表點（概略）」，不代表銀杏樹的精確位置。昭和紀念公園、新宿御苑、皇居東御苑等大型園區的代表點取在官方提到銀杏的區域附近（例如カナール、大溫室、百人番所），仍是概略位置。
- **步行時間**：園區代表點之間的直線距離 ÷ 每分鐘 80 公尺，每段四捨五入、最少 1 分鐘。不含園內步道與停留，也不含等紅綠燈、上下坡、繞路與搭車。
- **「約 30 分鐘」「約 1 小時」**：從使用者選的起點出發，每次加入最近的下一個地點，只要步行估時合計不超過 30／60 分鐘就繼續；下一個最近地點會超過時就停止並說明原因。找不到任何符合的地點時直接說明，不補上地點或路段；只有在「約 1 小時」從同一起點確實排得出路線時，才建議改選它（小金井公園、八王子、廣德寺離其他地點都超過 1 小時步行）。
- **導航**：Google 地圖連結使用代表點座標，步行模式；網址最多帶 9 個中途點，超過時改用各段連結。
- **中文地名**：為編輯譯名，不是官方名稱；日文原名一併列出。
- **官方資訊摘錄**：依官方頁面整理，所在地、交通、時間、費用多保留日文用語，但不是逐字引文；本站自己的查核說明一律用中文，寫在各欄的附註或「未能核實的欄位」。官方頁面沒有寫的欄位顯示「待確認（官方頁面未載明）」。

## 限制

- 資料是 2026-10-02 的整理快照，網站不會自動抓取官方更新。
- 第三方平台（tenki.jp、Weathernews、WalkerPlus、Jorudan、日本氣象株式會社）沒有用於任何狀態；Weathernews、Jorudan、WalkerPlus 的景點座標只參與部分代表點的取點。資料表為國立大學通附的 Jorudan 補充網址，在觀測卡上標為「第三方參考」，不算官方來源。
- OpenStreetMap 圖磚伺服器由志工營運，只適合低流量使用。若伺服器拒絕請求（例如回傳「Access blocked」圖片），網站會偵測到並顯示說明，不會把那張圖當地圖。
- 路線時間是估算，不是導航結果；實際路線請以 Google 地圖為準。
